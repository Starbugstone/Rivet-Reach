# Rivet Reach 0.1.0 Alpha

A Windows x64 playtest release of the current single-player survival, crafting and automation game. Built with Unity 6000.4.4f1, Direct3D 11 and the non-development Mono player.

## Download and play

Download **RivetReach-0.1.0-alpha-windows-x64.zip** from the [v0.1.0 release](https://github.com/Starbugstone/Rivet-Reach/releases/tag/v0.1.0). Extract the complete ZIP and run **RivetReach.exe**. Keep the adjacent data folder, DLLs and Mono runtime together. Unity and Blender are not needed. GitHub's automatic source archives are not the playable download.

Choose **Start Expedition** to begin empty-handed. Punch logs, collect them, and open inventory to craft planks, sticks and a Workbench. Place it and press **E** or right-click to open its 3×3 crafting grid. The inventory recipe browser shows ingredients and required stations.

## What is included

- Named Save Game, Load Game, Continue Latest Save and previous-checkpoint recovery. The original public 0.0.1 ZIP did not contain durable saves.
- Varied terrain, caves, biomes, water and lava; mining, building, slabs, connected Glass, doors and torches.
- Tools with durability, fitted armor, two explorer models and changeable local skins.
- Farming, orchards, cooking, composting, fishing, persistent chickens, beds and home respawn.
- Hostile creatures, underground Floaters and rare cage-spawner rooms.
- Day/night, lunar phases and weather.
- Furnaces and electric processing, industrial machines, item/fluid pipes, separate electricity and Blue Signal, tanks, batteries, crates, bridges and chunk loaders, plus steam, solar and wind generation.
- Ore/tool guidance, Home/Last death navigation, machine setup advice and saved frame-pacing choices.
- Optional session Creative mode with flight and the item catalog.

## Saving

Use **Escape → Save Game**, **Load Game**, or **Save & Quit**. **Continue Latest Save** resumes the latest checkpoint from the title screen. There is **no periodic autosave**; closing the window or quitting without saving loses unsaved changes.

Saves are stored in `%USERPROFILE%\AppData\LocalLow\Starbugstone\Rivet Reach\Saves`. This build writes schema 19 and retains supported historical-save compatibility checks. Back up existing local playtest saves before using a newer build; older executables cannot read newer save formats. Creative mode and flight reset on load. Stored items and construction persist. Dormant systems freeze and there is no offline production.

## Default controls

| Action | Control |
| --- | --- |
| Move / look | WASD / mouse |
| Jump / sprint / crouch | Space / Left Ctrl / Left Shift |
| Mine or attack | Hold left mouse |
| Place or use | Right mouse |
| Interact with a station | E or right mouse |
| Inventory / pause | Tab / Escape |
| Select hotbar | Mouse wheel; 1–0 for the first ten slots |
| Drop one / stack | Q / Shift+Q |
| Body view / diagnostics | F5 / F12 |

Controls can be rebound in Settings. For Creative testing, enable **Escape → Creative Mode**, then double-tap **Space** for flight. Space rises, Shift descends and Ctrl flies faster. **Tab → All Items** opens the catalog.

## Known alpha limits

This release is published at the owner's request for playtesting while the earlier performance hold remains unresolved as an acceptance finding. **Steady 60 FPS at 1080p is not certified.** The latest optimizations passed functional checks; new comparative FPS measurements remain deferred. Large factories, weather and traversal may stutter. Settings provides 90 FPS, display sync, 60 FPS and 120 FPS options; a cap is not a performance guarantee.

Progression/balance, distant scenery presentation and extended-session stability remain under review. Minimum hardware requirements and a second-machine run have not been established. Multiplayer, controller support and Linux/macOS builds are not included.

See the [release verification record](https://github.com/Starbugstone/Rivet-Reach/blob/main/.docs/verification/ALPHA_0_1_0_RESULTS.md) for exact build identity, measured checks and limits. The [player wiki](https://github.com/Starbugstone/Rivet-Reach/wiki) explains recipes and setup. [Report issues](https://github.com/Starbugstone/Rivet-Reach/issues) with reproduction steps, seed, settings and hardware; the default log is `%USERPROFILE%\AppData\LocalLow\Starbugstone\Rivet Reach\Player.log`.

`build-manifest.json` identifies the build source and hashes the payload. `SHA256SUMS.txt` contains the Windows ZIP checksum.
