# Rivet Reach 0.0.1 Alpha

The first downloadable Windows 64-bit alpha of Rivet Reach, a voxel survival, crafting and automation sandbox.

## Download and play

Download **RivetReach-0.0.1-alpha-windows-x64.zip** from the [v0.0.1 release](https://github.com/Starbugstone/Rivet-Reach/releases/tag/v0.0.1). Extract the whole ZIP to a folder, then run **RivetReach.exe**. Keep its data folder, DLLs and Mono runtime together. Unity and Blender are not required to play. GitHub's automatically generated source archives are for the project source; use the Windows ZIP to play.

Choose **Start Expedition** for a new world. You start empty-handed. Punch logs, collect them, then open inventory to craft planks, sticks and a workbench. Place the workbench and interact with it to make tools.

**Progress is session-only: quitting resets the world and inventory.** This is an early single-player alpha. Durable saves, multiplayer, Linux/macOS builds and controller support are not included. Art, balance and long-session performance remain under development; minimum hardware requirements have not been established.

## Included

- Terrain, caves, biomes, seas, rivers, water flow and buckets.
- Mining, building, inventory, recipe discovery, crafting and survival progression.
- Trees, farming, cooking, hunger, health, armor, torches and native creatures.
- Day/night, lunar phases, male/female appearances and local skins.
- Industrial machines, separate power/signal networks, item/fluid pipes, multiblock tanks and battery banks.
- Optional session Creative mode with flight and an item catalog.

## Default controls

| Action | Control |
| --- | --- |
| Move / look | WASD / mouse |
| Jump / sprint / crouch | Space / Left Ctrl / Left Shift |
| Mine or attack | Hold left mouse |
| Place or use | Right mouse |
| Interact with a station | E or right mouse |
| Inventory / pause | Tab / Escape |
| Select hotbar | Mouse wheel; 1–0 for the first ten slots |
| Drop one / stack | Q / Shift+Q |
| Body view / diagnostics | F5 / F12 |

For Creative testing, start an expedition, open **Escape → Creative Mode**, then double-tap **Space** to toggle flight. Space rises, Shift descends and Ctrl flies faster. **Tab → All Items** opens the catalog. Controls can be rebound in settings.

See the [player wiki](https://github.com/Starbugstone/Rivet-Reach/wiki) for construction guides and [report issues](https://github.com/Starbugstone/Rivet-Reach/issues) with reproduction steps, your world seed, settings and hardware. The default Windows player log is under `%USERPROFILE%\AppData\LocalLow\Starbugstone\Rivet Reach\Player.log`.
